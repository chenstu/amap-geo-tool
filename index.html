    为什么只能定位到城市？

    浏览器精确定位（几十米级）需要系统允许该浏览器使用「定位服务」，代码绕不过这一步；拿不到时只能用网络 IP 定位到城市。

    1 系统授权系统设置 → 隐私与安全性 → 定位服务 → 打开总开关 → 在列表里勾选你的浏览器（找不到就点 + 手动添加）

    2 网站权限点地址栏左侧的锁形图标 → 位置 → 允许；Chrome 还可在 设置 → 隐私和安全 → 网站设置 → 位置信息 中检查

    3 打开方式确保用双击「启动工具.command」打开（http://localhost）；预览面板的 iframe 可能禁用定位

    4 换浏览器Safari 定位经常直接超时，用 Chrome 打开同一个 localhost 地址再试，多数一次就成功

    5 硬件条件台式 Mac 走以太网时系统定位能力很弱，连上 Wi-Fi 再试；实在不行用「地图选点」最可靠
